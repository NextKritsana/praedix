ค ำศัพธืทั้งหมดที่เกี่ยวกับ System ACS
• Address Bus (บัสแอดเดรส): เส้นทำงที่ใช้ส่งแอดเดรสหน่วยควำมจ ำจำก CPU ไปยังอุปกรณ์ต่ำงๆ
• Address Space Layout Randomization (ASLR): เทคนิคกำรป้องกันหน่วยควำมจ ำที่สุ่ม
ต ำแหน่งของพื้นที่แอดเดรสหน่วยควำมจ ำเมื่อโปรแกรมก ำลังท ำงำน เพื่อท ำให้กำรโจมตี Buffer
Overflow ยำกขึ้น
• ALU (Arithmetic Logic Unit): ส่วนหนึ่งของ CPU ที่รับผิดชอบในกำรค ำนวณจริง ท ำกำร
ด ำเนินกำรทำงคณิตศำสตร์และตรรกะ
• Application Software (ซอฟต์แวร์ประยุกต์): โปรแกรมที่ท ำหน้ำที่ตำมที่ผู้ใช้ต้องกำร เช่น
Microsoft Office หรือเกม
• Assembly Language (ภาษาแอสเซมบลี): ภำษำคอมพิวเตอร์ที่แปลงภำษำเครื่องให้เป็นรูปแบบที่
มนุษย์อ่ำนได้ง่ำยขึ้น โดยมีกำรจับคู่ 1:1 ระหว่ำงค ำสั่งแอสเซมบลีและภำษำเครื่อง
• Bind Shellcode: Shellcode ที่ท ำให้ผู้โจมตีสำมำรถเชื่อมต่อกับพอร์ตเฉพำะบนระบบเป้ำหมำย
• Buffer: พื้นที่หน่วยควำมจ ำชั่วครำวที่ใช้เก็บข้อมูลขณะที่ข้อมูลก ำลังถูกย้ำยจำกต ำแหน่งหนึ่งไปยังอีก
ต ำแหน่งหนึ่ง
• Buffer Overflow: เกิดขึ้นเมื่อข้อมูลมีขนำดเกินกว่ำ buffer ที่จัดสรรไว้ ท ำให้ข้อมูลส่วนเกิน
เขียนทับพื้นที่หน่วยควำมจ ำข้ำงเคียง
• Bus Interface (อินเตอร์เฟซบัส): อุปกรณ์ภำยใน CPU ที่เข้ำใจโปรโตคอลกำรสื่อสำรของบัส I/O
• __cdecl: Calling convention ที่พำรำมิเตอร์ถูกส่งผ่ำน stack จำกขวำไปซ้ำย และผู้เรียก
(caller) เป็นผู้รับผิดชอบในกำรล้ำง stack
• Caller (ผู้เรียก): ฟังก์ชันหรือโค้ดที่เรียกใช้ฟังก์ชันอื่น
• Callee (ผู้ถูกเรียก): ฟังก์ชันที่ถูกเรียกใช้
• Canary Leak: กำรค้นหำค่ำ canary ที่รั่วไหลออกมำ ซึ่งสำมำรถเกิดขึ้นได้หำกค่ำ canary มี null
byte อยู่ข้ำงหน้ำและถูกพิมพ์ออกมำ
• Code Segment (CS): รีจิสเตอร์เซกเมนต์ที่ EIP อ้ำงอิง มีแอดเดรสเริ่มต้นของพื้นที่โค้ด
หน่วยควำมจ ำ
• Compiled Language: ภำษำที่คอมไพเลอร์แปลง source code ทั้งหมดเป็น machine
language ก่อนกำรรัน

## Page 2

• Computer Architecture (สถาปัตยกรรมคอมพิวเตอร์): ชุดของกฎและวิธีกำรที่อธิบำยฟังก์ชัน,
องค์กร และกำรน ำไปใช้ของระบบคอมพิวเตอร์
• Control Bus (บัสควบคุม): เส้นทำงที่ใช้ส่งสัญญำณควบคุมจำก CPU ไปยังอุปกรณ์ต่ำงๆ
• Control Unit (CU): ส่วนหนึ่งของ CPU ที่ตีควำมค ำสั่งและส่งต่อให้ ALU ท ำงำน
• Data Area: พื้นที่หน่วยควำมจ ำที่เก็บตัวแปรส่วนกลำงและตัวแปร static
• Data Bus (บัสข้อมูล): เส้นทำงที่ใช้ส่งข้อมูลระหว่ำง CPU และอุปกรณ์ต่ำงๆ
• Data Execution Prevention (DEP): เทคนิคกำรป้องกันหน่วยควำมจ ำที่ป้องกันกำรรันโค้ดใน
พื้นที่หน่วยควำมจ ำที่ไม่มีสิทธิ์ในกำรด ำเนินกำร
• Debugger: เครื่องมือที่ใช้ในกำรวิเครำะห์โปรแกรมขณะที่ก ำลังรันอยู่ (dynamic analysis)
• Decode: ขั้นตอนที่ CPU ตีควำมค ำสั่งที่น ำเข้ำและวิเครำะห์ว่ำค ำสั่งเหล่ำนั้นต้องกำรอะไร
• Disassembler: เครื่องมือที่สร้ำง assembly code จำก machine language code (static
analysis)
• DWORD (Double Word): ชนิดข้อมูล 32-bit unsigned integer ในภำษำแอสเซมบลี
• Egg-hunting: Shellcode แบบ staged ที่แทรก shellcode จริงไว้ในต ำแหน่งที่คำดเดำได้ และ
เรียกใช้โดยใช้ tag เพื่อค้นหำต ำแหน่งของ shellcode จริง
• EFLAGS Register: รีจิสเตอร์ที่แสดงสถำนะปัจจุบันของโปรเซสเซอร์ (เช่น Zero Flag, Carry
Flag)
• Endianness: วิธีกำรจัดเรียงไบต์หลำยๆ ไบต์ในพื้นที่หนึ่งมิติ เช่น หน่วยควำมจ ำของคอมพิวเตอร์
(Little-endian, Big-endian)
• EIP (Extended Instruction Pointer): รีจิสเตอร์ที่เก็บแอดเดรสของค ำสั่งถัดไปที่ CPU จะ
ด ำเนินกำร
• Epilogue: ส่วนท้ำยของฟังก์ชันที่ท ำควำมสะอำด stack และคืนค่ำ EBP และ EIP (RETN)
• ESP (Extended Stack Pointer): รีจิสเตอร์ที่ชี้ไปที่ด้ำนบนสุดของ stack ใช้ส ำหรับค ำสั่ง
PUSH, POP , RET และ CALL
• Execute: ขั้นตอนที่ CPU ด ำเนินกำรค ำสั่งที่ตีควำมแล้วบน ALU
• __fastcall: Calling convention ที่ใช้ ECX ส ำหรับอำร์กิวเมนต์แรก, EDX ส ำหรับอำร์กิวเมนต์ที่
สอง และ stack ส ำหรับอำร์กิวเมนต์ที่เหลือ ผู้ถูกเรียก (callee) เป็นผู้ล้ำง stack

## Page 3

• Fetch: ขั้นตอนกำรดึงค ำสั่งจำกหน่วยควำมจ ำไปยัง CPU และจัดเก็บข้อมูลในรีจิสเตอร์
• Heap Area: พื้นที่หน่วยควำมจ ำที่จัดเก็บข้อมูลเมื่อมีกำรจัดสรรหน่วยควำมจ ำแบบไดนำมิก ข้อมูลจะ
เพิ่มขึ้นในทิศทำงแอดเดรสสูง
• IA-32 Architecture (Intel Architecture 32-bit): สถำปัตยกรรม CPU 32-bit ของ Intel
• Interpreted Language: ภำษำที่ interpreter อ่ำน source code ทีละบรรทัดและด ำเนินกำร
โดยตรง
• JIT (Just-In-Time) Language: ภำษำที่ JIT compiler แปลงแต่ละภำษำเป็น bytecode เฉพำะ
• JMP (Jump): ค ำสั่งในภำษำแอสเซมบลีที่ท ำให้โปรแกรมกระโดดไปยังแอดเดรสที่ระบุ
• Linear Address Space: พื้นที่แอดเดรสเสมือนที่มองเห็นส ำหรับกำรดีบัก โดยทั่วไปก ำหนดค่ำได้
สูงสุด 4GB ส ำหรับ 32-bit CPU
• Little-endian: วิธีกำรจัดเรียงไบต์ที่จัดเก็บตำมล ำดับจำกไบต์ต ่ำสุดก่อน
• Local Shellcode: Shellcode ที่ใช้เพื่อหำประโยชน์จำกช่องโหว่ เช่น Buffer Overflow เพื่อเพิ่ม
สิทธิ์ในระบบเป้ำหมำย
• Main Memory (หน่วยความจ าหลัก): RAM; พื้นที่ที่โค้ดโปรแกรมถูกโอนย้ำยและด ำเนินกำร
• Machine Language (ภาษาเครื่อง): ภำษำที่คอมพิวเตอร์เข้ำใจได้โดยตรง ประกอบด้วยรหัส
binary
• Metasploit: เฟรมเวิร์กที่ใช้ในกำรสร้ำงและจัดกำร payloads และ shellcode
• NOP Sled: ล ำดับของค ำสั่ง NOP (No Operation) ที่ใช้ในกำรโจมตี Buffer Overflow เพื่อเพิ่ม
โอกำสที่ EIP จะกระโดดไปยัง shellcode ที่ฉีดเข้ำไป
• Null Byte (0x00): ไบต์ที่มีค่ำเป็นศูนย์ มักใช้เป็นตัวสิ้นสุดสตริง
• OllyDbg: Debugger ยอดนิยมส ำหรับวิเครำะห์โค้ด binary x86 (dynamic analysis)
• Operand (ตัวถูกด าเนินการ): ค่ำหรือต ำแหน่งในหน่วยควำมจ ำที่ค ำสั่งกระท ำกำร
• Prologue: ส่วนเริ่มต้นของฟังก์ชันที่ตั้งค่ำ stack (PUSH EBP , MOV EBP , ESP)
• Register Set (ชุดรีจิสเตอร์): พื้นที่หน่วยควำมจ ำภำยใน CPU ส ำหรับจัดเก็บข้อมูลชั่วครำว
ควำมเร็วสูง

## Page 4

• Remote Shellcode: Shellcode ที่ใช้โดยผู้โจมตีเพื่อโจมตีระบบเป้ำหมำยอื่นบนเครือข่ำย โดยใช้
กำรเชื่อมต่อ socket TCP/IP
• Reverse Engineering (การวิศวกรรมย้อนกลับ): กระบวนกำรในกำรค้นพบหลักกำรทำงเทคนิค
ของอุปกรณ์หรือระบบโดยกำรวิเครำะห์โครงสร้ำงของมัน
• Reverse Shellcode / Connect-back Shellcode: Shellcode ที่ท ำให้ระบบเป้ำหมำยร้อง
ขอกำรเชื่อมต่อไปยังผู้โจมตี
• RET (Return): ค ำสั่งในภำษำแอสเซมบลีที่ท ำให้โปรแกรมกลับไปยังแอดเดรสที่ถูกเรียกก่อนหน้ำ
• Return-to-Library (RTL): เทคนิคกำรโจมตีที่เรียกฟังก์ชันในไลบรำรีที่โหลดอยู่ในหน่วยควำมจ ำ
โดยตรง เพื่อบำยพำสกำรป้องกัน DEP
• SFP (Saved Frame Pointer): ค่ำ EBP เก่ำที่ถูกเก็บไว้บน stack ก่อนเข้ำสู่ฟังก์ชันใหม่
• Shellcode: โค้ดขนำดเล็กที่เขียนในภำษำเครื่อง ใช้เพื่อหำประโยชน์จำกช่องโหว่ในซอฟต์แวร์
• Stack Area: พื้นที่หน่วยควำมจ ำที่จัดเก็บข้อมูลชั่วครำว เช่น ตัวแปรภำยในและพำรำมิเตอร์ ท ำงำน
แบบ Last In First Out (LIFO) ข้อมูลจะเพิ่มขึ้นในทิศทำงแอดเดรสต ่ำ
• Stack Canary: กลไกกำรป้องกัน Buffer Overflow ที่แทรกค่ำสุ่มระหว่ำง stack buffer และ
return address เพื่อตรวจจับกำรเปลี่ยนแปลง
• __stdcall: Calling convention ที่พำรำมิเตอร์ถูกส่งผ่ำน stack จำกขวำไปซ้ำย และผู้ถูกเรียก
(callee) เป็นผู้รับผิดชอบในกำรล้ำง stack
• Staged Shellcode: Shellcode ที่ด ำเนินกำรเป็นขั้นตอนเมื่อมีข้อจ ำกัดในกำรรันโดยตรง
• Static Analysis (การวิเคราะห์แบบสถิตย์): วิธีกำรวิเครำะห์ซอฟต์แวร์โดยไม่จ ำเป็นต้องรัน
โปรแกรม
• strcpy (string copy): ฟังก์ชัน C ที่คัดลอกสตริงจำกแหล่งที่มำไปยังปลำยทำง แต่ไม่มีกำร
ตรวจสอบควำมยำว buffer ซึ่งอำจน ำไปสู่ Buffer Overflow
• System Exploitation (การหาประโยชน์จากระบบ): กระบวนกำรในกำรหำประโยชน์จำกช่องโหว่
ด้ำนควำมปลอดภัยในระบบคอมพิวเตอร์เพื่อเข้ำถึงโดยไม่ได้รับอนุญำตหรือบิดเบือนกำรท ำงำนของ
ระบบ
• System Software (ซอฟต์แวร์ระบบ): โปรแกรมที่จัดกำรและควบคุมกำรท ำงำนของฮำร์ดแวร์และ
ซอฟต์แวร์ เช่น ระบบปฏิบัติกำร

## Page 5

• Text Area: พื้นที่หน่วยควำมจ ำที่เก็บโค้ดส ำหรับโปรแกรมที่จะด ำเนินกำร
• TLS (Thread Local Storage): พื้นที่เก็บข้อมูลที่แต่ละเธรดสำมำรถเข้ำถึงได้โดยไม่รบกวนเธรดอื่น
• von Neumann Architecture (สถาปัตยกรรม von Neumann): กำรออกแบบโครงสร้ำง
คอมพิวเตอร์ที่มีบัสเดียวส ำหรับทั้งข้อมูลและโปรแกรม ท ำให้มีกำรประมวลผลหน่วยควำมจ ำตำมล ำดับ
• WinExec: ฟังก์ชัน Windows API ที่ใช้ในกำรรันโปรแกรมหรือค ำสั่ง
• XOR (Exclusive OR): กำรด ำเนินกำรบิตไวส์ทำงตรรกะที่ให้ผลลัพธ์เป็น 1 หำกบิตอินพุตต่ำงกัน
และ 0 หำกบิตอินพุตเหมือนกัน
• ZF (Zero Flag): แฟล็กในรีจิสเตอร์ EFLAGS ที่ตั้งค่ำเป็น 1 หำกผลลัพธ์ของกำรด ำเนินกำรทำง
คณิตศำสตร์คือ 0
