Steganography05
Steganography
A technique for hiding information, secretly embedding and transmitting
data within other media files, such as messages, images, audio, video, etc.
Basic principles of steganography
The core principles of steganography are "hide" and "communicate".
1.Prepare the data to hide: Prepare the secret message or information you want to send.
2.Select cover media: Select the host media (image, audio, video file, etc.) that you want to hide information from.
3.Insert Data: Insert data to be hidden into cover media using a special algorithm
                       This process ensures that there are no noticeable changes to the appearance or functionality of the cover media.
4.Data transfer: Send cover media with hidden data to a recipient
5.Data extraction and restoration: Recipients use special keys or algorithms to extract and restore hidden data

Steganography is a technique that utilizes various media to hide data or messages.
It can conceal information in different ways, and here are some of the most common use cases.
LSB Technique
Hiding information by changing the Least

while minimizing visual changes to the
image.
For example, when hiding a text message

manipulated to conceal the information in
a form that is virtually indistinguishable
from the original image.
Audio Steganography
Hiding information by fine-tuning the

is usually a change so subtle that it is
difficult to distinguish with the human ear.
Information can be hidden by making it
impossible or difficult to hear in a music file
or voice recording, which can be used to
convey confidential messages.
Video Steganography
A method of hiding information within a
frame, either by manipulating the LSB of
each frame or by utilizing changes
between frames.
Additional information can be hidden in
security camera footage or personal videos
for use in security systems or for personal
purposes.

Least Significant Bit (LSB)
The manipulation of bits, the smallest unit of data in media such
as images or audio files, to hide information.
LSB Technique
Uses the lowest-ranked bit of data (i.e., the rightmost bit), such as the color value of a pixel. Because this bit
does not have a significant impact on the overall value of the data, changing it is barely noticeable visually or
audibly.
For example, in a 24-bit color image, each pixel is composed of three color channels-red, green, and blue-with
each channel represented by eight bits. Using the LSB technique, you can change the last of these bits to hide
information.
Use cases
Digital Image Concealment , Audio Steganography , Secure Communications
Limitations
The LSB technique is simple and effective, but hidden information can be corrupted when images or audio are
compressed or edited.

Hash Value Comparison
A hash function is a function that takes data of arbitrary length as input and
outputs a hash value (or message digest) of fixed length. The hash value acts as
a unique "fingerprint" of the input data, and even the smallest change to the
original data will result in a significantly different hash value.
After generating a hash value for an image file, you store it and later recalculate
the hash value for the same image and compare it. If the two hash values match,
it means that the image has not been altered; if they don't, it indicates that the
image has been manipulated or altered. Hash functions commonly used include
MD5, SHA-1, SHA-256, and others.
Digital Signature
A digital signature is a way to authenticate the owner of an electronic document
or file and ensure data integrity. Digital signatures are created using public key
cryptography, signed with the owner's secret key, and can be verified by anyone
with the owner's public key. When creating a digital signature for an image file,
the hash value of the file is first calculated, and the hash value is encrypted with
the owner's private key and signed.
The recipient can verify the integrity of the file and the owner's authenticity by
decrypting the hash value using the public key, while simultaneously computing
the hash value of the file themselves and comparing the two values to see if they
match .Digital signatures are used to ensure ownership and data integrity in
important documents, software distributions, online transactions, and more.
Digital signatures can be applied to image files in the same way to protect the
integrity of the original. Hash value comparison and digital signature technologies
play an important role in enhancing the security of a wide range of digital content,
not just images. These techniques are essential tools for detecting whether an
image has been manipulated, which contributes to ensuring that data is reliable
and safe.
