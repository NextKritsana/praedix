Main Topic ForenChain : developing a digital forensics platform that uses blockchain
technology to guarantee the integrity of evidence
Reasons to
choose this
subject
This topic was chosen for its high relevance in the current cybersecurity landscape.
Digital evidence integrity is a critical challenge in forensic investigations, as evidence
can be easily altered or tampered with. This project directly addresses this iss ue by
leveraging Blockchain technology to create an immutable and auditable chain of
custody. Furthermore, it integrates multiple forensic disciplines (network and disk)
into a single, streamlined platform, solving the common problem of using separate,
complex tools for analysis. This blend of security, forensics, and modern software
engineering makes it a challenging and innovative subject.
 Project Plan
  How do you plan to run your project?
• The project will be executed using an Agile methodology, broken down into
key phases:
1. Phase 1: Planning & Design (Weeks 1 -2): The team will finalize
the system architecture, design the UI/UX, define the database
schema, and set up the development environment (Git, Docker).
2. Phase 2: Development Sprints (Weeks 3- 10): The work will be
divided into two-week sprints focusing on:
 Developing the Smart Contract for the chain of custody.
 Building the core backend APIs and business logic.
 Implementing the forensic analysis modules for .pcap
and .dd files.
 Developing the user interface (frontend) and integrating it

  What tools will you use?
• Frontend: React.js / Vue.js
• Backend: Python (with libraries like Scapy, pyewf, requests)
• Blockchain: Ethereum (Sepolia Testnet) with Solidity
• Database: PostgreSQL or MongoDB
• External APIs: VirusTotal API
• Analysis & Environment: Docker, Kali Linux, Packet Tracer
• Collaboration: Git/GitHub, Trello/Jira, Discord/Slack

Project Results
(expected)
The primary expected outcome is a functional web application prototype named
"ForenChain" with the following key features:
1. A secure system for uploading digital evidence (.pcap and .dd files).
2. A working Blockchain- based Chain of Custody that logs hashes of all
evidence and analysis reports.
3. A user dashboard displaying automated analysis results from VirusTotal
(malicious files, IPs, and hashes).
4. Downloadable analysis reports for each investigation.
5. A significant enhancement of the team members' practical skills in their
respective domains.
