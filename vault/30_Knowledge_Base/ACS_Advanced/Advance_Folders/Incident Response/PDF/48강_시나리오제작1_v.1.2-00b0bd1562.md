function PWUnzip{
    $install7z = "C:\Program Files\Microsoft Mail\7z.exe"
    $zipFilePath = "C:\Program Files\Microsoft Mail\mail.zip"
    $7zipPath = "C:\Program Files\7-Zip\7z.exe"
    Start-Process $install7z /S -Wait -PassThru
    & $7zipPath x $zipFilePath -pACS1234 -y
}
• Installation of the 7-Zip program
• Decompressing compressed files
What it does
• Run the 7-Zip installer stored in $install7z in install mode using the Start-Process command
• The /S switch means Silent Mode, which does not require user interaction during the installation process
• The -Wait option pauses the script execution until the installation process is complete
• The -PassThru option returns information about the installation process, allowing you to utilize that information within the script
Install 7-zip
• Install7z: Location of the installation file in 7z
• zipFilePath: location of the downloaded compressed reverse connection
• 7zipPath: Store 7z's executable file location, C:\Program Files\7-Zip\7z.exe, in a variable
