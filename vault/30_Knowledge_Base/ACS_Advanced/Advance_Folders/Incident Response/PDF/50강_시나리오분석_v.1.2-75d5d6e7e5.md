function Remove-FirstByte {
    param (
        [string]$FilePath
    )
    $content = [System.IO.File]::ReadAllBytes($FilePath)
    $newContent = $content[1..($content.Length - 1)]
    [System.IO.File]::WriteAllBytes($FilePath, $newContent)
}
Script description
• The $FilePath parameter represents the path to the file to be processed.
• Use [System.IO.File]::ReadAllBytes($FilePath) to read all bytes from a file at the specified path in binary form and
return the contents of the file as a byte array
• Assign the byte array, except for the first byte, to a new variable $newContent by slicing it
• Write the modified byte array back to the original file path using [System.IO.File]::WriteAllBytes($FilePath,
$newContent)
• If you have a large number of targeted
files, using a script is more effective
