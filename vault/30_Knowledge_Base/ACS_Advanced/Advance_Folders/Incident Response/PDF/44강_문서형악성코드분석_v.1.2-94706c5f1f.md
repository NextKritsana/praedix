VBS risks and precautions
• Pose a serious risk to users and systems when exploited
• Malicious scripts can be used to manipulate system settings,
steal sensitive information, and install additional malicious
software
• By hiding code through script encoding, malicious activity can
be hidden from the eyes of the public
VBA risks and precautions
• If possible, you should review the contents of the script to
determine if it contains code that performs unintended or
harmful actions
• Use trusted antivirus software to protect your system and scan
VBS files before running them
• Macros using VBA can contain viruses or malicious code
• If a user runs a maliciously crafted macro, an attacker could
gain access to your system or steal sensitive information
• Change settings to run only trusted macros
• Maximize security settings for Office applications
• Enable macros only when needed
