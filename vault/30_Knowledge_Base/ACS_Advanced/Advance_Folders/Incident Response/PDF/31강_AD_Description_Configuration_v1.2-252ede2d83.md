• In Active Directory, replication refers to the process of synchronising
information about a domain between domain controllers
• This process is an important part of Active Directory because it
ensures that all domain controllers have the same information, which
helps maintain consistency in the network and ensures that services
are not interrupted if one of the domain controllers fails
• Multiple replication master
• Means that domain controllers have equal authority, and changes
can be written from any controller
• Changes are then replicated to other domain controllers in the
network
• The replication process does not replicate the entire database, but
only the information that has changed since the last replication
• Contributes to minimising network traffic
Replication
