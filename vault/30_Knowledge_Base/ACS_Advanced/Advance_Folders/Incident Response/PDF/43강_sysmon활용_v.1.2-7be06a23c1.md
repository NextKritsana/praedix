Fine-grained filtering rules
• Sysmon can log a variety of events, but enabling logging of all events can negatively
impact system performance
• Make sure you clearly understand what behavior each rule is trying to detect on your
system and why it is needed
• If you add a rule to detect the creation of a specific process, be clear about why that
process is of interest and what security threat it is related to
Ongoing management and updates
• The security landscape is constantly changing, and configuration files must be managed
and updated to keep up with these changes
• For example, if a new piece of malware uses a process with a specific name, it needs to be
registered and logged in the configuration file
Sufficient validation
• When importing configuration files from external sources, verify the credibility of the
source
• Prefer configuration files from official, well-known communities or organizations
• Review the file to ensure it has been recently updated to address the latest security threats
